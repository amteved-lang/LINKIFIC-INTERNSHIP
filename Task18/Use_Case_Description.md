# Customer Support AI Agent - Use Case

## Use Case

A customer contacts the HearMe AI Voice Agent and asks:

"What is the refund policy for my service?"

## Agent Execution

### Step 1 - Receive Query

The agent receives the customer's question.

### Step 2 - Understand Intent

The agent identifies the intent as:

Refund Policy Information

### Step 3 - Plan

The agent determines that company documentation must be searched.

### Step 4 - Select Tool

The agent selects the RAG Retrieval Tool.

### Step 5 - Retrieve Information

The RAG system searches the company knowledge base and retrieves the relevant refund-policy information.

### Step 6 - Evaluate Information

The agent checks whether the retrieved information is sufficient to answer the question.

### Step 7 - Generate Response

The agent prepares a grounded response using the retrieved information.

### Step 8 - Escalation

If the required information cannot be found or the customer's situation requires manual review, the agent escalates the request to a human support agent.

## Expected Result

The customer receives a relevant response based on company information without requiring a human agent for routine questions.
