# LangGraph Multi-Agent System

## Project Overview

This project implements a multi-agent research workflow using LangGraph for the HearMe company project.

The system uses specialized agents that communicate through shared state.

## Learning Objectives

- LangGraph Integration
- Agent Communication
- State Management
- Error Handling
- Multi-Agent Systems
- Conditional Routing

## Agents

- Coordinator Agent
- Research Agent
- Analyzer Agent
- Critic Agent
- Writer Agent
