# HearMe Company API - Production Readiness

## Project Overview

This project improves the HearMe company API by adding software testing, logging, environment variables, Docker configuration, documentation, and monitoring.

## Learning Objectives

- Pytest
- Unit Testing
- API Testing
- Logging
- Docker Basics
- Environment Variables
- Monitoring
- Production Readiness

## Features

- FastAPI application
- Company information search
- Input validation
- Unit tests
- API tests
- Application logging
- Rotating log files
- Environment variables
- Docker configuration
- Health monitoring
- Basic request metrics
