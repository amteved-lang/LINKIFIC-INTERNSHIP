# Project Presentation Notes

## Opening

Hello, my name is Ved Amte. Today I will present my AI company project based on the HearMe AI Customer Support System.

The project focuses on building an AI-powered customer support platform using concepts such as RAG, FastAPI, AI agents, LangGraph workflows, tool calling, responsible AI, testing, logging, and production readiness.

## Problem Statement

Customer support teams handle many repetitive queries. This increases workload and response time.

The goal of this project is to automate routine support queries while keeping sensitive or complex cases under human supervision.

## Solution

The solution is an AI-powered support system that can:

- Accept user questions
- Search company documentation
- Retrieve relevant answers
- Route sensitive queries to human support
- Maintain workflow state
- Use agent-based decision making
- Follow responsible AI practices

## Architecture

The architecture includes:

User  
↓  
FastAPI Backend  
↓  
RAG System  
↓  
AI Agent  
↓  
Tool Calling  
↓  
Human Escalation  
↓  
Final Response
