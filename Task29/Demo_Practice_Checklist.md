# Demo Practice Checklist

## Before Demo

- [ ] Open VS Code
- [ ] Open the correct project folder
- [ ] Check all Task folders
- [ ] Confirm README files are updated
- [ ] Confirm code runs without errors
- [ ] Keep terminal ready
- [ ] Keep browser ready
- [ ] Keep GitHub repo open
- [ ] Keep presentation notes open

## During Demo

- [ ] Introduce project objective
- [ ] Explain problem statement
- [ ] Show architecture
- [ ] Show folder structure
- [ ] Run FastAPI server
- [ ] Open Swagger UI
- [ ] Test normal query
- [ ] Test human escalation query
- [ ] Show README
- [ ] Show reports and documentation
- [ ] Explain challenges
- [ ] Explain future improvements

## After Demo

- [ ] Ask for feedback
- [ ] Note mentor suggestions
- [ ] Update README if required
- [ ] Commit final changes
- [ ] Push to GitHub
