# 🤖 Large Language Models & Hugging Face

## Project Overview

This project explores Large Language Models (LLMs), Generative AI, and pre-trained AI models using the Hugging Face Transformers library.

Three different models were tested for:

- Text Generation
- Sentiment Analysis
- Text Summarization

## Learning Objectives

- Understand the evolution from Machine Learning to Generative AI
- Understand the basics of Large Language Models
- Explore the Hugging Face Model Hub
- Use pre-trained AI models
- Compare outputs from different NLP models
