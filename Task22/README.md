# Multi-Agent Research Assistant

## Project Overview

This project designs a Multi-Agent Research Assistant for the HearMe company project.

The system uses multiple specialized AI agents that communicate using a shared workflow state.

## Learning Objectives

- Agent Roles
- Agent Communication
- Shared State
- Workflow Planning
- Multi-Agent Architecture
- Responsibility Management

## Agents

The system contains five agents:

- Coordinator Agent
- Research Agent
- Analyzer Agent
- Critic Agent
- Writer Agent

## Workflow

```text
User Query
    ↓
Coordinator
    ↓
Research Agent
    ↓
Analyzer
    ↓
Critic
    ↓
Writer
    ↓
Coordinator
    ↓
Final Response
