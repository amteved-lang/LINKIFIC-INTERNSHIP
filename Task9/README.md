# 📊 Exploratory Data Analysis - Student Performance

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a cleaned student performance dataset using Python, Pandas, Matplotlib, and Seaborn.

The analysis explores academic performance, attendance, subject-wise trends, relationships between variables, and overall student patterns.

## Objectives

- Explore the cleaned dataset
- Perform descriptive statistical analysis
- Identify trends and patterns
- Analyze relationships between variables
- Create meaningful visualizations
- Generate business-style insights

## Analysis Performed

- Dataset overview
- Descriptive statistics
- Subject-wise performance analysis
- Student performance ranking
- Attendance analysis
- Correlation analysis
- City-wise performance analysis
- Gender-wise performance analysis

## Visualizations

1. Average Marks by Student
2. Attendance vs Average Marks
3. Distribution of Average Marks
4. Average Marks by Subject
5. Correlation Heatmap

## Business Insights

- Identified the highest-performing student
- Identified the lowest-performing student
- Analyzed attendance patterns
- Identified the strongest-performing subject
- Examined the relationship between attendance and academic performance

- Seaborn
